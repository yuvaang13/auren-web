How it works

Enforcement lives below the browser.

Prompt guardrails argue with the model. Auren sits at the OS layer, where agents actually act — so a DNS NXDOMAIN, a killed process, and a fingerprint gate don’t negotiate.

DNS blocking

Protection ON points system DNS at Auren’s local resolver. Blocked domains answer NXDOMAIN in every app and browser — including headless ones agents open themselves.

OS firewall

Command ports, known DoH/DoT endpoints, and cloud-metadata IPs are blocked at the OS — pf anchor on macOS, firewall rules on Windows. Tunnels and “Secure DNS” bypasses fail.

App blocking

Blocked apps are killed the moment they start — and kept stopped — system-wide, no matter which process launched them. Exact-path matching, never substrings.

Autofill & HTTPS hostnames

Saved passwords, addresses, and cards can’t be auto-filled while protected. A loopback SNI proxy refuses blocked HTTPS hosts by name — without decrypting anything, ever.

Protection Mode

One switch. Your fingerprint holds the key.

Turning protection on is instant. Turning it off — or quitting the app — requires Touch ID / Windows Hello or your device passcode, plus a 5-second cooldown where everything stays blocked. An agent can’t quietly undo it.

  1. Flip it on. First run installs the background service (one admin prompt); every later flip is instant.
  2. Work normally. Allowed sites, apps, and files behave exactly as before.
  3. Agents hit the wall. Blocked lookups fail, tunnels die, exfil pipelines get denied before they run.

Auto-protect Beta

Auren watches for live agent sessions — headless browsers, Playwright / Puppeteer / Selenium drivers, CLI agents, Cursor & co. — and raises protection itself when it spots one while you’re unprotected. Detection needs a persistent, confident match, so stray words never trip it. It only ever raises protection; lowering it is always your fingerprint.

File System Guard

Agents see exactly one folder. Yours.

Mount a workspace like learningPython and every agent file request routed through Auren is checked: canonicalized (symlinks and ../ collapsed), screened against forced exclusions, then contained to your mounts. Anything else is refused before the read happens.

Default-deny mounts

The agent starts with zero file access. Only folders you explicitly mount are visible through Auren’s gates — stored encrypted, locally.

Forced exclusions

.env, .ssh, .aws, *.pem / *.key, browser credential stores — always denied, even inside a mount. Never removable.

Traversal-proof

Symlink escapes and workspace/../.env tricks collapse to their real location first — then get denied.

Honest scope: the guard covers agent file access routed through Auren (loopback bridge, terminal-command gate, path checks). It doesn’t lock Finder / File Explorer for you — you stay trusted; the agent stays leashed.

Privacy

Zero-knowledge. Local-only.

No blocklists, mounts, paths, or activity data are ever collected or transmitted. No telemetry, no account, no cloud. Your policy lives in your OS app-data directory, encrypted at rest (AES-256-GCM) and signed (HMAC) — and the daemon verifies it on every poll.

  • No file contents or full paths ever logged — basenames and labels only
  • Biometrics never touch Auren — only pass/fail from Touch ID / Hello
  • Fail-closed: if enforcement can’t be verified, gates refuse by default
  • Activity log is append-only, on your disk, readable by you

Honest limits

What Auren does not claim.

  • Not a Finder/Explorer lock — it leashes agents, not you.
  • Not a sandbox — unlisted processes run freely; app blocking is an exact-path kill-loop.
  • Not content inspection — the HTTPS proxy reads hostnames only, never payloads.
  • DoH blocking covers known endpoints; a self-hosted resolver isn’t on the list.
  • Assumes a non-compromised machine — root-level attackers are out of scope.

FAQ

Questions, answered.

How do I install the unsigned beta builds?

Mac: open the .dmg, drag Auren to Applications, then right-click → Open on first launch to bypass Gatekeeper once. Windows: run the installer, then SmartScreen → “More info” → “Run anyway”. Signed builds are on the roadmap.

Which platforms are supported?

macOS (Apple Silicon and Intel) and Windows 10/11. Protection uses the pf anchor on macOS and firewall rules on Windows; DNS, proxy, autofill, and agent gates work on both.

Will it break my normal browsing?

No. Allowed sites resolve and load exactly as before. Only domains, apps, and ports you block are affected — and flipping protection OFF restores everything within about a second.

Does the File Guard lock my own folders?

No — you can always open anything in Finder/Explorer. The guard constrains what AI agents can read through Auren, so secrets outside your mounted workspace stay out of agent reach.

What happens if something goes wrong?

Auren fails closed: if the background service stops responding or its integrity can’t be verified, every gated surface refuses by default and the app shows a degraded banner with a one-click service reinstall.

Is there a price / subscription?

The beta is free. A subscription with synced policies across machines and a cloud dashboard is planned — your local-only posture stays the default.
